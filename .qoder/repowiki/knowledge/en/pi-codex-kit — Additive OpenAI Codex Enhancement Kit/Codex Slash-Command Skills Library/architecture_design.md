Flat collection of independent skill directories under `skills/`, each a self-contained unit installable by copying into `~/.codex/skills/` (or via cc-switch). Every skill exposes one entry point — `SKILL.md` — written in Markdown with YAML frontmatter (`name`, optional `model`, `description`, `allowed-tools`) that Codex parses to register the slash command. Supporting assets live alongside: `agents/openai.yaml` per skill (agent model config), plus domain-specific subdirectories such as `fp-check/references/`, `variant-analysis/resources/{codeql,semgrep}/`, `differential-review/{methodology,adversarial,patterns,reporting}.md`, and `simplify/scripts/simplify-context.mjs`. There is no shared runtime or build system inside this module; skills are purely declarative prompts + reference material consumed at invocation time by the Codex agent.
