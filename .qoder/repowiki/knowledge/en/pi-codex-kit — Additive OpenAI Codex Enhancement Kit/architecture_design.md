The repository is a flat collection of independently-installable Codex extensions rather than a single application: `hooks/` provides Node.js PreToolUse/PostToolUse scripts that Codex invokes via `hooks.json`, `mcp-servers/` ships the pi-lens MCP server (16 tools) registered through `config.toml`, and `skills/` delivers self-contained slash-command skill folders consumable by either cc-switch or Codex's native skill loader. There is no shared runtime or library between children — each directory is a drop-in artifact with its own README, prerequisites, verification checklist, and rollback path, all orchestrated at the top level only by this README's quick-start table and the optional AGENTS.md workflow glue.
