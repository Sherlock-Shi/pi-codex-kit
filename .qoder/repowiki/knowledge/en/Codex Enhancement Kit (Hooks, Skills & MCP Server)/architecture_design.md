Flat collection of independently-installable Codex extensions with no shared runtime or library between children — each directory is a drop-in artifact with its own README, prerequisites, verification checklist, and rollback path. `hooks/` provides Node.js PreToolUse/PostToolUse scripts invoked via `~/.codex/hooks.json`, `mcp-servers/` ships the pi-lens MCP server (16 tools) registered through `config.toml`, and `skills/` delivers self-contained slash-command skill folders consumable by either cc-switch or Codex's native skill loader. Orchestration at the top level is purely documentary: this README's quick-start table plus the optional AGENTS.md workflow glue section that tells the agent how to compose the three pieces together.
